# `vk_bot/` — VK-бот для демонстрации

Демонстрационный бот для VK: принимает произвольное сообщение, отправляет его обученной модели через OpenAI-совместимый API (vLLM) и возвращает исправленный текст.

## Структура

| Файл | Назначение |
| --- | --- |
| `bot.py` | Точка входа: обработчики сообщений ([vkbottle](https://github.com/vkbottle/vkbottle)), приветствие и основной хендлер коррекции. |
| `spell_service.py` | Изолированная обёртка над spell-correction API (асинхронный `AsyncOpenAI`-клиент с переиспользованием соединений). |
| `config.py` | Централизованная конфигурация: токены, параметры генерации, промпт и тексты сообщений (читаются из `.env`). |
| `requirements.txt` | Зависимости бота. |

## Конфигурация

Создайте файл `.env` в этой директории:

```env
VK_TOKEN=<токен сообщества VK>
SPELL_API_KEY=<api-key vLLM>
SPELL_API_BASE_URL=http://localhost:9900/v1
SPELL_MODEL=spell_correction
```

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

> Требуется запущенный vLLM-сервер с моделью (см. корневой [README](../README.md#-запуск-модели)), доступный по адресу из `SPELL_API_BASE_URL`.

## Как работает

1. Пользователь пишет боту любой текст.
2. На приветствия/команды (`привет`, `/start`, `help`, …) бот отвечает справкой.
3. Любое другое сообщение оборачивается в промпт и отправляется модели; исправленный текст возвращается пользователю.
4. Ошибки API/сети логируются и обрабатываются мягко — пользователь получает сообщение об ошибке вместо падения.
