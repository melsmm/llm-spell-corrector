# `data/` — данные проекта

Здесь хранятся все данные: исходные корпусы, обучающие датасеты, предсказания модели на бенчмарках, итоговые метрики и графики статистик.

> ⚠️ Крупные файлы (`.csv`, `.gz`) хранятся через **Git LFS**. Итоговые обучающие датасеты также опубликованы на Hugging Face: [`melsmm/spell-correction-ru`](https://huggingface.co/datasets/melsmm/spell-correction-ru/tree/main).

## Структура

### `datasets/`
Сырые («чистые») корпусы текстов, в которые синтетически вносились ошибки.

- `nerus_lenta.conllu.gz` — корпус новостей Lenta.ru с морфо-синтаксической разметкой ([nerus](https://github.com/natasha/nerus)). Используется как основной источник чистых предложений.

Дополнительно в ноутбуках на лету подгружаются корпусы `IlyaGusev/gazeta` и `misterkirill/ru-wikipedia` (не хранятся в репозитории).

### `spell_corr_datasets/`
Готовые обучающие датасеты (пары «правильный текст» → «текст с ошибкой»).

- **`synth_spell_correction_1m.csv`** — синтетический датасет, ~1 млн примеров. Используется на **Stage 1** обучения.
- **`spell_correction_30k.csv`** — объединение готовых пар из открытых датасетов, ~30 тыс. примеров. Используется на **Stage 2**.
- `russian_gec_dataset.csv` / `russian_gec_dataset/data.csv` — исходный датасет готовых пар (GEC), один из источников для 30k.

Формат обучающих датасетов:

| Колонка | Описание |
| --- | --- |
| `text` | эталонный (правильный) текст |
| `text_corrupt` | текст с внесёнными ошибками (вход модели) |
| `source` | источник текста (`nerus`, `gazeta`, `RUSpellRU`, …) |
| `method` | способ порчи (`ready_pair`, `sbsc`, `char_aug`, `punct_corruption`, `mixed_*`, …) |

### `pred_data/`
Предсказания итоговой модели на тестовых сплитах бенчмарков (по одному CSV на датасет): `RUSpellRU`, `MultidomainGold`, `MedSpellchecker`, `GitHubTypoCorpusRu`.

Формат: `source_text` (вход), `ground_truth` (эталон), `model_prediction` (ответ модели).

### `metrics/`
Итоговые таблицы метрик на бенчмарке.

- `spell_correction_stage_1.csv` — метрики модели после Stage 1.
- `spell_correction_stage_2.csv` — метрики итоговой модели (Stage 2).

Колонки: общие `Precision/Recall/F1` и разбивки по `CASE_*` (регистр), `SPELL_*` (орфография), `PUNCT_*` (пунктуация), `YO_*` (буква «ё»).

### `graphics/`
Графики статистик по обучающим датасетам, сгенерированные в ноутбуках построения данных.

- `synth_spell_correction_1m/` — распределения для 1M-датасета: по методам порчи, по источникам, длины текстов, гистограмма CER, доля изменённых примеров.
- `spell_correction_30k/` — аналогичные распределения для 30k-датасета.
